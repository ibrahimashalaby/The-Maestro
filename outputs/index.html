Local-first by default

Privacy & settings

Control the data stored by this browser and see what leaves it during a review.

What is stored locally

Your optional Digital Twin (region, economic situation, rent, housing budget, tenancy and notes), saved review summaries, source links and editable drafts, and lens preference. These live in this browser’s local storage and are not synced.

What is sent for a review

After you check the consent box, the app sends your question, region, tenancy type, selected lens, optional notice text and optional public URL to this app’s local server. Exa receives a generalized legal search and, when provided, the public URL for extraction. Claude receives the submitted question and notice plus returned Exa evidence. Your local profile and calculated rent amounts are excluded. Exa is the only web search provider used.

Periodic opportunity search

Only when you opt in, a search repeats every six hours while this browser tab is visible. Exa receives the selected region and category. Turning it off or closing the tab stops the timer.

Provider keys

Exa and Claude credentials belong on the local server as environment variables. They are never placed in browser code. This demo does not transmit data to analytics services.

Clear local data

Remove the profile, imported web trail, chat history and reviews saved by Maestro in this browser. Extension storage is managed separately in the browser companion popup.
